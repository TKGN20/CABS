# Measured results

Each reproduction command creates a new timestamped directory. Raw datasets,
indexes and newly generated runs are excluded from Git. Completed runs include
`metrics.json`, `resolved_config.json`, original query/ID records, source/input/
binary hashes and logs; a failed run retains `manifest.json` with `status=failed`.

Use `python3 scripts/evaluate.py RUN_DIRECTORY` to independently recompute
Recall/QPS and validate complete timing records, query-set separation, exact
ranking, and IT/IS accounting. This validates the supplied exact-GT records;
the production-path smoke test also independently checks exact sparse scores.

Two verified local WSL examples are checked in under `measured/splade-0.1m/`
and `measured/splade-1m/`. Each has all 6,976 evaluation queries x three repeats.
GT, retrieved IDs and timing CSVs are losslessly gzip-compressed; the evaluator
reads them without manual decompression. `artifact_manifest.json` protects
immutable evidence files with SHA-256, while `provenance.json` records input,
source and binary hashes, hardware, and Git line-ending normalization. Original
vectors and private machine paths/logs are not included. Derived `metrics.json`
and `audit.json` can be regenerated from the immutable records.

The former repository's experimental outputs remain in the Git history at the
base commit recorded in `docs/source_provenance.json`. They were generated by a
different implementation and are not measurements of these public defaults.
Current manuscript estimates are not copied into measured output.
