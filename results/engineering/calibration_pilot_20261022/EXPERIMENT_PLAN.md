# 本轮预先确定的诊断范围

1. 核心默认配置不变。生产 include/src 不变；不手工钳制 K/m/B，不改变 suffix stopping 条件或删除困难目标。
2. 0.1M 完整自动校准试验：四种配置按 (nc=4,kmax=100)、(8,50)、(4,50)、(8,100) 顺序各新建一次完整索引，所有候选 K/local m/B 重新校准。ell=24、delta_h=0.2、seed=20261007、Lloyd=10、build=4、query=1，其余同公开设置。
3. 四个配置比较同一组 64 条查询，取固定 shuffled query IDs 的第 8..71 位，与全部 8 条候选校准查询分离。nc=4 的正式输出额外包含第 4..7 位，保存但不进入 common-validation 比较。所有三轮计时均保留。共同查询的前 5 条均预热，前 8 条均作未计时参考路径核对。
4. 该试验是参数/配置改变的诊断，不是等价内核优化、同 Recall 胜负、多独立构建或跨数据集鲁棒性证明。不会自动推广为新的默认值。失败配置保留日志，不用目标数值替换。
5. 对已完成 1M 的实际 K=8/B=51385 索引重建：16 条固定查询记录每簇 gamma/suffix/角度/覆盖半径/范数界；前 4 条还穷举真实簇最大内积，检验上界松紧。全部此类扫描和 trace 在 QPS 计时外。
6. 对已有四条校准查询的临时 proxy 前缀排名作所有非空子集与 kmax=50/100 的事后预算计算，仅作为固定 m/hash/partition 的 B 规则诊断，不冒充重新校准整个方法的运行结果。
7. 新服务器 baseline 同 Recall 比较仅准备可审批协议，本轮不声称已执行。
